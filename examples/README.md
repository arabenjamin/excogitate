# Examples: the Daily News Brief, end to end

A showcase of the runtime and its plugins doing one real job: a daily news
brief, searched, written, and its claims kept with their sources. Each
plugin here was stamped from the plugin template, the way yours would be,
and each is compiled into the app behind its own feature.

| Plugin | What it does | Status |
|---|---|---|
| [`search`](search) | Web search through TinyFish, the key attached by the runtime | built |
| `newsbrief` | The brief's sources, and the workflow that writes it | next |

Plugins outside `examples/` and `plugins/example` aren't part of the
runtime; these show how one is built and used, and keep to the same
checks as the rest of the repo.
